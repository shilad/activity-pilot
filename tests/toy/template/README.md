# Practice assignment

A short warm-up. You will run two scripts, record what they print, and check your work.

## Part 1

1. Run `part1.py` (ask Claude to run it for you).
2. Put the number it prints in `WRITEUP.md` under Part 1, and write one sentence on what the script computes.
3. Commit your work with the message "Part 1 done".

## Part 2

1. Run `part2.py`.
2. Put the number it prints in `WRITEUP.md` under Part 2.
3. Commit your work with the message "Part 2 done".

## Check

Run `run_all.py`. It lists any answer that is still blank. When every answer is filled in it prints
`YOU ARE FINISHED!`.
