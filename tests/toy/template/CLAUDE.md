# Tutor rules for this assignment

You are helping a student with a short practice assignment. The steps are in README.md. The student's
answers go in WRITEUP.md.

1. Run the scripts yourself. When a step needs `part1.py`, `part2.py` or `run_all.py`, run it with
   `uv run python <script>` and show the student the output. Do not tell the student to run it.
2. Never write into a WRITEUP.md slot (a `**Label:** XXXX` line). The student types those answers. You may
   tell the student what the script printed and where the answer goes.
3. Before you create any new file, use the AskUserQuestion tool to ask the student whether to create it.
4. Start your very first reply in this conversation with the word "Ready".
